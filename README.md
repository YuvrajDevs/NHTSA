# Vehicle Safety Intelligence

> **Status: in progress.** The pipeline runs end to end on real NHTSA data; a final clean run, its generated reports and the last write-up are still to do. See [STATUS.md](STATUS.md) for exactly what is done and what is left.

A governed **batch data product** on public US road-safety data (NHTSA): 2.3 million consumer complaints, 330,000
recall records and 154,000 investigation records, refreshed daily, modelled into a star schema, checked by data
contracts, documented in a generated catalog, prepared for AI, and orchestrated with Airflow.

**The question it answers:** *which vehicle components are trending toward a recall, and could complaints have warned
us before past recalls?*

**Project page:** [`site/`](site/) (GitHub Pages not switched on yet) · **How it was built (every decision and failure):** [docs/build-log.md](docs/build-log.md)

```
NHTSA daily files ─► landing (zips + SHA-256 manifest) ─► bronze (every line as received)
   complaints               │                                   │
   recalls                  │                       silver: typed, cleaned, quarantine,
   investigations           │                       daily change detection (I/U/D), SCD2 for recalls
                            │                                   │
                            │                       gold (SQL): star schema + data products
                            │                       ├── fact_complaint, fact_recall_vehicle, fact_investigation
                            │                       ├── dim_vehicle, dim_component, dim_manufacturer, dim_state, dim_date, dim_recall_campaign
                            │                       └── mart_component_risk_monthly, mart_recall_early_warning, mart_manufacturer_scorecard
                            │                                   │
                   data contracts (quality gate) ─► AI-ready documents + similarity search ─► generated catalog + lineage
                                         orchestrated daily by Airflow (logical date, retries, backfill-safe)
```

## Results (measured on the real data)

| What | Result |
|---|---|
| Data | 2,270,295 complaint rows (1.6 GB text), 330,395 recall rows, 154,505 investigation rows |
| Full refresh, 4-core laptop | bronze ~1 min · silver ~6 min · gold ~1.5 min (12 tables, 3.4M rows) · quality ~1 min |
| Change detection, simulated day with known changes | **750/750 complaint and 750/750 recall changes detected, 0 missing, 0 extra** |
| Data contracts | 89 checks on 15 tables; the first run found **6 real problems in NHTSA's data** (build-log F6). Report: generated by `quality` (published after the final run) |
| Silent data loss caught | 35,423 rows lost to a NULL-in-key join, found by reconciliation and fixed (F5) |
| AI-ready layer | 1.63M documents, 47,551 personal details removed (phones, emails, VINs, links) |
| Daily MERGE tuning | 1.79 GB -> 0.89 GB written, 70 s -> 44 s, for 750 changed rows ([docs/performance.md](docs/performance.md)) |
| Tests | 15 pytest tests (Spark), GitHub Actions CI; Airflow DAG run end to end in Docker |

**What the data says** (`gold.mart_recall_early_warning`, 19,160 vehicle recalls since 2000):

| Recall size (units affected) | Recalls | Preceded by matching complaints | Spike signal fired first | Median lead time |
|---|---|---|---|---|
| 100,000+ | 1,366 | **91%** | 27% | ~1 year |
| 10,000-100,000 | 2,354 | 55% | 16% | ~1 year |
| 1,000-10,000 | 4,027 | 23% | 7% | 442 days |
| under 1,000 | 11,418 | 8% | 4% | 412 days |

## Quick start (no accounts needed)

**You need:** Python 3.10-3.12, Java 17 ([Temurin](https://adoptium.net/)), ~6 GB free disk. Docker only for Airflow.
On Windows use WSL2 (Ubuntu).

```bash
git clone https://github.com/YuvrajDevs/NHTSA.git && cd NHTSA
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pytest -q                                          # 15 tests, ~2.5 min (starts Spark)
python -m vsi.cli run                              # today's NHTSA data, all steps (~12 min)
python -m vsi.cli search "brake pedal went to the floor"
```

Faster first try: `VSI_SAMPLE_ROWS=20000 python -m vsi.cli run` (20k rows per source, row-count checks become warnings).

**Airflow:** `docker compose up -d --build`, open http://localhost:8080 (user `admin`, password from
`docker compose logs airflow | grep -i password`), un-pause `vsi_daily`.

### Commands

| Command | Does |
|---|---|
| `python -m vsi.cli download --date D` | fetch NHTSA files to `data/landing/D/` (skips unchanged files) |
| `python -m vsi.cli bronze / silver / gold --date D` | one layer |
| `python -m vsi.cli quality --date D` | run all data contracts, write `docs/quality-report.md` (exit 1 if blocking) |
| `python -m vsi.cli ai` / `catalog` | AI documents + index / data catalog |
| `python -m vsi.cli run --date D` | everything, in order |
| `python -m vsi.cli rebuild SOURCE` | replay silver for one source from bronze |
| `python scripts/simulate_next_day.py` then `verify-changes --date D+1` | prove change detection is exact |
| `python scripts/perf_merge.py` | the MERGE performance experiment |
| `./scripts/demo.sh` | all of the above, end to end |

## Data
U.S. National Highway Traffic Safety Administration, Office of Defects Investigation: complaints, recalls and
investigations flat files (`static.nhtsa.gov/odi/ffdd/`). Public domain. Consumer narratives are published by NHTSA;
this project still scrubs contact details before using them for AI.
